# Your Tax Partner

Vytvoř mi moderně vypadající web, který bude sloužit jako vizitka/prezentace daňového poradce a zároveň si bude moct zákazník poptat jeho službu. Web by měl být jednoduchý, přehledný, s dobrým UX a UI. Bude mít HomePage s několika podstránkami - o mně (kde klient uvidí reference, mou práci atd), kontakt (kde najde kontaktní údaje a poptávkový formulář) a stránku služby (kde najde klient ceník a nabízené služby).
